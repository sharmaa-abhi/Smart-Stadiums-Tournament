## 1. Test Suite Execution Commands

```bash
# Run Vitest Unit Tests
npm run test

# Run Vitest with Coverage Report
npm run test:coverage

# Run Playwright End-to-End Tests
npm run test:e2e

# Run Extreme Role-Based Auth Verification Suite
npm run test:all:extreme
```
