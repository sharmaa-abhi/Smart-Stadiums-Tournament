## 🚀 Overview

**StadiumGenius** is an AI-powered smart stadium platform designed for FIFA World Cup 2026 venues. It helps operators monitor crowd movement, manage incidents, visualize stadium activity, and make faster decisions using real-time analytics.

---

## ✨ Features

- 🤖 AI Operations Assistant
- 🏟️ Digital Twin Dashboard
- 👥 Crowd Monitoring
- 🛡️ Security & Incident Management
- 📊 Live Analytics
- 🍔 Concession Queue Tracking
- 📡 Real-time Updates (SSE)
- 🔐 JWT Role-Based Authentication

## ⚡ Getting Started

### Install

```bash
npm install

cd server
npm install
```

### Run

Backend

```bash
cd server
npm run dev
```

Frontend

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
