## 🚀 Overview

**StadiumGenius** is an AI-powered smart stadium platform designed for FIFA World Cup 2026 venues. It helps stadium operators monitor crowd movement, manage security incidents, visualize stadium digital twin activity, and make rapid operational decisions.

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run backend API server
cd server
npm run dev

# 3. Run frontend application
npm run dev
```

Open `http://localhost:5173` in your browser.
